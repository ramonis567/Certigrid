# Supabase

This folder will hold the database assets for the Certigrid MVP.

Phase 1 scope:

- Reserve the location for migrations and seed data.
- Keep environment secrets out of source control.

Planned tables:

- `energy_assets`
- `simulation_rules`
- `measurement_records`
- `certificate_batches`
- `certificate_batch_measurements`
- `negotiations`
- `certificate_claims`
- `lifecycle_events`
- `solana_transactions`
